## 1. 工場・倉庫（既定カテゴリ）
- 読者: 工場・倉庫のオーナー、施設管理・総務・営繕担当者、経営者
- 主ニーズ: 暑さ対策（熱中症・空調コスト）、雨漏り、結露、サビ、予算消化・稟議
- 建物: 折板屋根・波形スレート屋根、鉄骨造
- 現行プロンプトの文脈をそのまま維持

## 2. 畜舎（牛舎・豚舎・鶏舎・飼料タンク）
- 読者: 暑熱対策・老朽化対策を検討する畜産農家（企画書の定義）、農業法人の施設担当者
- 使える数値（自社試験・公的機関）: 屋根表面温度 最大18.6℃低下・裏面6.1℃低下（アステックペイント試験）、折板屋根表面は夏季70℃超、THI 68以上で牛に影響・72超で乳量・受胎率に明確な影響（農畜産業振興機構・農業試験場）、屋根裏温度5℃以上低下（農林水産省試験データ）。引用機関: 農林水産省、農畜産業振興機構、岡山県畜産研究所、佐賀県畜産試験場
- 推奨製品: 超低汚染リファイン500Si-IR（コスト重視）／500MF-IR（長寿命）。スレート屋根はEC-100PCM
- 主ニーズ: 暑熱ストレスによる家畜の生産性低下（増体・乳量・産卵率）、屋根・外壁の老朽化と雨漏り、結露・カビ、防疫（バイオセキュリティ）を守りながらの工事
- 建物: 折板屋根・スレート屋根の平屋、飼料タンク
- 訴求: 屋根遮熱で屋根表面温度 最大20℃／屋根裏 6℃以上低下、光熱費削減、結露防止塗装、タンク遮熱・防カビ、ノンスリップ塗床
- 事例: K社（島根県・畜産業、2018年6月、折板屋根遮熱）
- 禁止表現: 工場向け固有語（「生産ライン」「作業員の熱中症」中心の書き方）。畜舎では家畜の生産性・獣医/防疫の観点を主軸に

## 3. 店舗・量販店
- 読者（優先）: 複数店舗を持ち本部機能がある企業の設備・保全担当者（ドラッグストア／スーパー・ディスカウント／ホームセンター／量販店／飲食）。自社所有8割・貸店舗2割
- 次点: 単独オーナー店舗。貸店舗は不動産オーナー
- 意思決定: ①本社の設備・保全担当がニーズの大きい店舗から計画（例: まいばすけっと・キリン堂・サイゼリヤ） ②店舗責任者が保全を担い本社へ申請
- 建物: 1,000〜2,000㎡の折板屋根がほとんど。全館空調・天井ありのため「暑さ」はほぼ刺さらない
- ニーズ優先順: 電力コスト（空調電気代）＞ 天井結露によるカビ ＞ 美観（ブランドイメージ・集客・求人）
- 大手はCN宣言・店舗CO2削減が会社目標（例: ウェルシア）
- 雨漏りはほぼ無い（売上に直結するため即対応済み）→ 雨漏り訴求は弱い
- 営業しながら施工できるかは「当然」なので訴求にならない
- 事例を求められるが店舗での空調費削減実績は未保有 → 倉庫事例で代替し、断定的な店舗実績を書かない
- 多店舗一括発注のディスカウントは記載OK（参考: LIXIL工場50拠点で実施）
- 塗料: 低コスト志向で「シャネツテックSi-JY」施工が多い（トップワンは店舗では非採用）。公式サイトの現行製品名は「シャネツテックⅡSi-JY」（https://astecpaints.jp/products/detail/54、期待耐用年数13〜16年、屋根専用20色）→ 製品レコメンドは店舗カテゴリでこれを第一推薦に切替
- 響く工場向けサポート: 稟議資料サポート、認定施工店ネットワーク・全国対応、塗装・板金・防水・雨漏り・塗床の一括対応、メーカー直結の品質
- 執筆の主軸: 遮熱＝電気代・CO2削減の投資回収、結露カビ対策（ケツロナイン）、美観・ブランド、多店舗一括発注・本部決裁のしやすさ

## 4. 施設（私立学校・老健施設（老人ホーム）・病院・宿泊施設）
- 表記は必ず「施設（私立学校・老健施設（老人ホーム）・病院・宿泊施設）」。公立・自治体案件（公共工事）は対象外と明記
- 読者: 各施設の「決裁者」（学校は理事長、病院は会長など。名称は「決裁者」で統一）、施設管理・総務担当
- 建物: RC造メイン・陸屋根。体育館は瓦棒屋根
- ニーズ優先順: 老朽化（長寿命化・安全対策）＞ 雨漏り ＞ 美観
- 意思決定: 病院・老人ホームは修繕計画に沿って計画的（数年先の工事に向けて業者を調査・選定）。学校は修繕計画なく都度対応が多い。学校は「廊下が暑い」など暑さ対策需要あり
- 悩みの発生源: 現場担当者・法人本部の両方
- 響く訴求: RC造の傷み具合を評価する「調査報告書」、補助金・助成金（私立学校向け「空調設備整備臨時特例交付金」等は要ファクトチェック）、高耐候塗料（足場代削減のため長寿命を好む）、高耐候シーリング、弾性フィラー（エピテックフィラー）
- 書かない: 工事中の安全対策（施工店依存）、瑕疵保険・保証内容
- 製品: エピテックフィラーAEⅡ（https://astecpaints.jp/products/detail/67、水性一液エポキシ系可とう形下地調整材、RC・モルタル・ALC対応、JIS A 6909合格）を下地補修に、上塗りは無機REVO1000-IR／リファイン1000MF-IR。陸屋根防水は astec-factory.com/waterproof.html（ウレタン塗膜防水 8,000円/㎡〜、シート防水 9,000円/㎡〜、シーリング打ち替え 900円/m〜）
- 補助金の注意: 「空調設備整備臨時特例交付金」は避難所指定の学校体育館等の空調整備が対象（補助率1/2）。私立学校の外壁・屋根改修には「私立学校施設整備費補助金」等が該当しうる。制度名・対象・補助率・年度は記事化時に必ず文科省等の一次情報でファクトチェックする

## 送客ルート（企画書より）
業種KW検索 → ブログ記事 → 業種別LP → TOP → 会社概要・選ばれる理由 → 問い合わせ。
記事の自社サービス訴求H2には該当カテゴリの業種別LPへの内部リンクを1箇所入れる（実装: `services/facilityCategoryConfig.ts` の `servicePageUrl`）。

## カテゴリ別の禁止・注意
| カテゴリ | 避ける文脈 |
|---|---|
| 全カテゴリ | 戸建て・アパート・マンション・オフィスビル向け語（管理組合・修繕積立金・入居者等）、アステックペイントが直接施工する表現 |
| 店舗 | 「暑さで作業員が…」「雨漏りで困っている店舗」を主訴にする構成 |
| 施設 | 公立学校・自治体・公共工事を読者にする、鉄骨折板屋根前提の記述 |
| 畜舎 | 工場の生産ライン前提の記述 |
